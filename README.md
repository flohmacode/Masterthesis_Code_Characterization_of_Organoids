# Masterthesis_Code_Characterization_of_Organoids

Code accompanying a Master's thesis on the metabolic characterization of organoids using ³¹P magnetic resonance spectroscopy (MRS), chemical shift imaging (CSI), and mechanistic/statistical modeling of organoid metabolism.

The project rests on three pillars, each in its own folder:

| Folder | Pillar | What it does |
|---|---|---|
| [`spectroscopy/`](./spectroscopy) | 1D ³¹P-MRS | Reads raw Bruker NSPECT scans, processes FIDs into spectra, fits peaks, and analyses metabolite time courses (ATP, inorganic phosphate) |
| [`csi_spectroscopy/`](./csi_spectroscopy) | 3D Chemical Shift Imaging | Reads Bruker CSI/TurboRARE scans, reconstructs k-space images, and overlays spectroscopic voxel grids on anatomical (axial/coronal/sagittal) images |
| [`modeling/`](./modeling) | Mechanistic & statistical modeling | Simulates organoid metabolism (glucose/oxygen consumption, ATP/waste production), fits the model to the spectroscopy data via Approximate Bayesian Computation (ABC), runs a Sobol sensitivity analysis, and models residuals with a Gaussian Process |

Each of the three folders contains its own `src/` subfolder with the shared, frequently-reused functions (file I/O, filtering, processing, plotting) that the top-level analysis scripts import.

Supporting folders:
- [`FIGURES_MASTERTHESIS/`](./FIGURES_MASTERTHESIS) — final figures used in the thesis (ABC posteriors, Sobol/sensitivity plots, GP residual fits, raw scan photos, schemes)
- `fig_csi/` — output figures generated by the CSI scripts

## The three pillars in more detail

### 1. Spectroscopy (`spectroscopy/`)
Raw ³¹P-NSPECT scans from a Bruker MRI/MRS system are read directly from the scanner's study/`pdata` folder structure (`file_utils.read_bruker_study`, `read_bruker_header`), converted from FIDs to spectra via FFT after exponential line broadening (`processing.linebroadening`, `spectroscopy.read_NSPECT`), and analyzed for metabolite peaks (γ-ATP, α-ATP, β-ATP, inorganic phosphate). Scripts here reproduce the organoid metabolic time-course plots (e.g. `analyse_spectradecay.py`) and the "minimum detectable amount" and stress-signal comparisons used in the thesis.

### 2. CSI Spectroscopy (`csi_spectroscopy/`)
Extends the same Bruker-reading infrastructure to 3D Chemical Shift Imaging data. `mr_imaging.py` reconstructs anatomical TurboRARE images from k-space (coil combination + inverse FFT, using `sigpy` and `brukerapi`), while `csiplots2stable.py` and the `csi_overlay_*.py` scripts overlay the spatially-resolved CSI voxel spectra grid onto the anatomical image in the three standard orientations (axial, coronal, sagittal).

### 3. Modeling (`modeling/`)
A mechanistic ODE-style model (`connection_to_bio.simulation_sensitivity_organoids`, `organoid_sim_linear.py`) simulates glucose and oxygen consumption, ATP production, and waste accumulation in an organoid over time, using Michaelis–Menten-type kinetics. The pipeline then:
- fits model parameters to the real spectroscopy-derived ATP/inorganic-phosphate time courses using an **Approximate Bayesian Computation (ABC) rejection sampler** (`rejection_sampler.py`),
- runs a **Sobol global sensitivity analysis** over the model parameters using `SALib` (`sensitivity_analyse.py`),
- fits a **Gaussian Process** to the residuals between the mechanistic model and the real data across two independent experiments (`GP.py`), and
- compares the resulting posterior parameter distributions between datasets (`posteriorcomparasion.py`).

Fitted parameter sets and processed inputs for two experimental datasets (`jojo_april`, `leupold_feb`, plus a third `leupold_dec`) are cached as `.npy` files under `modeling/parameters/` and `modeling/processed_data/`.

## Data

Raw Bruker scan data (`csi_data/`, `spectroscopy/data/`) is **not included** in this repository (excluded via `.gitignore`) since it consists of large, unpublished raw scanner exports. Scripts expect this data to be placed locally in the paths referenced at the top of each script (e.g. `./spectroscopy/data/<experiment_name>`, `./csi_data/<experiment_name>`) before they can be run end-to-end. Processed intermediate results (`.npy` files) for several experiments are included under the various `processed_data/` folders, so downstream analysis/modeling scripts (e.g. `analyse_spectradecay.py`, `rejection_sampler.py`, `GP.py`) can be run without the raw data.

## Usage

Each analysis script is a standalone entry point — set the experiment/study path/name at the top of the file, then run it directly, e.g.:

```bash
# Process raw spectroscopy scans into spectra
python spectroscopy/analyse_study_spectragif.py

# Plot metabolite time courses from processed spectra
python spectroscopy/analyse_spectradecay.py

# Fit the mechanistic model to experimental data via ABC
python modeling/rejection_sampler.py

# Sobol sensitivity analysis
python modeling/sensitivity_analyse.py

# CSI overlay on anatomical scan
python csi_spectroscopy/csi_overlay_axial.py
```

Because several scripts use relative imports of the form `import src.xxx` or `import modeling.src.xxx`, run them from the corresponding top-level folder (or the repository root, depending on the script) so the imports resolve correctly.
